🎬 视频提示词编写指南

T2VA · I2VA · FL2VA · L2VA 全参考模式 · Full‑Reference 🧒 儿童友好版

📌 第一部分：基础生成模式 (T2VA / I2VA / FL2VA / L2VA)

1.1 任务概览

T2VA文本 → 完整视听时间线
I2VA首帧指令 + 向前发展的视觉路径
FL2VA首尾帧指令 + 连续路径
L2VA末帧指令 + 收敛至末帧
🧒
五岁解释： 这些英文缩写是四种不同的“拍电影”方式。
• T2VA：就像你给AI讲一个故事，它帮你画出画面、配上声音。
• I2VA：你先给它一张“开头照片”，它从这张照片接着往下演。
• FL2VA：你给它“开头”和“结尾”两张照片，它帮你把中间的过程连起来。
• L2VA：你只给它“结尾”的照片，它倒着推理出开头应该是什么样子。

1.2 最终提示词结构

指令（Instruction）

  • T2VA：无图像对齐，直接从三个核心字段开始。
  • I2VA：
    对于目标视频，在目标视频的第 0.00 秒处，完全参考 <Picture 1>（来自 [Shot 1]）。
  • FL2VA：
    参考图像与目标视频的对齐方式 —— 图 1（来自 Shot 1）对齐目标视频的第 0.00 秒；图 2（来自 Shot N）对齐目标视频的第 S.SS 秒。
  • L2VA：
    参考图像与目标视频的对齐方式 —— <Picture 1>（来自 [Shot N]）对齐目标视频的第 S.SS 秒。

三个核心字段

integrated_multimodal_description: [Shot 1] …… overall_soundscape: …… non_diegetic_music: ……
  • integrated_multimodal_description：沿时间线描述画面、动作、镜头、说话人、对白、歌唱及画面内音效。
  • overall_soundscape：环境音、物理动作音效、非语言人声。
  • non_diegetic_music：只有观众能听到的背景音乐。
🧒
五岁解释： 这三个字段就是给你的“电影剧本”分成了三个部分：
• 第一段：写“画面里发生了什么”，就像讲故事。
• 第二段：写“环境里的声音”，比如雨声、脚步声。
• 第三段：写“背景音乐”，只有观众能听到，角色听不到。

1.3 关键帧融入策略

I2VA：从图像出发向前发展

<Picture 1> 是 0.00 秒的实际首帧。描述应首先确立图像中的风格、主体、构图和场景锚点，再描述后续动作。角色身份、服装、颜色、关键物品和空间关系应保持一致。

推荐结构 首帧锚点 → 动作起始 → 连续发展 → 结果或反应

FL2VA：描述首尾帧之间的路径

图1为开头，图2为结尾。重点描述主体移动、姿态变化、物体操作、构图演变及场景/光线过渡。FL2VA 通常倾向单一镜头以便插值。末帧必须在视频结束时由最后的 [Shot N] 到达。

推荐结构 首帧状态 → 可观察的中间变化 → 差异逐渐收窄 → 末帧状态

L2VA：推断开头，落在结尾的图像上

<Picture 1> 是最后一帧，属于最后一个 [Shot N]。根据用户意图和末帧推断合理的更早状态，然后描述如何逐渐接近参考图像。

推荐结构 合理的前置状态 → 明确的动作与过渡路径 → 在最后镜头中逐渐收敛 → 落在末帧

🧒
五岁解释： “关键帧”就是电影里最重要的几张“照片”。
• I2VA：你给了一张“开头照片”，AI就接着往下编故事。
• FL2VA：你给了“开头”和“结尾”两张照片，AI就自己想象中间发生了什么。
• L2VA：你只给了“结尾”照片，AI倒着猜出开头，再演到结尾。

1.4 核心编写规则（共用）

① 沿时间线展开多模态描述

integrated_multimodal_description 是主体。每个细节对应可视或可听内容：视觉风格、初始构图、主体外观与位置、场景与关键道具、动作与反应、镜头切换、口语内容及同步画面内声音。

在 [Shot 1] 开头说明整体风格和初始构图。常见风格：Cinematiclive-action2D-animated3D CGclaymationwatercolorvintage film。

[Shot 1] 实拍风格，电影感，一个中远景镜头框住……

② 镜头与切换

第一个镜头不加时间戳。后续镜头使用连续编号并以严格递增的切换时间开头：

[Shot 2] 在 00:03.500 时，镜头切至……

普通切换使用“镜头切至”“画面切至”等；仅在用户明确要求时使用叠化、淡入淡出或划像。如果只需要改变距离或轻微角度，优先使用镜头运动而非切换。

③ 镜头运动：运动类型 + 幅度 + 速度

维度可用表达说明
运动类型推近变焦 / 拉远变焦机身不动、焦距变化
运动类型推进 / 拉出摄像机前后移动
运动类型左摇 / 右摇机身不动、镜头水平转动
运动类型左移 / 右移摄像机水平平移
运动类型上仰 / 下俯机身不动、镜头垂直转动
运动类型升 / 降镜头整个摄像机上下移动
运动类型弧形镜头围绕主体做弧线运动
运动类型跟拍镜头跟随移动主体
运动类型固定镜头位置和镜头保持静止
运动类型轻微 / 强烈抖动镜头抖动
运动类型主观视角 (POV)主体第一人称视角
运动类型顺时针 / 逆时针滚转绕镜头轴滚转
幅度幅度较小 / 幅度较大小范围 / 大范围变化
速度速度较慢 / 速度较快缓慢 / 快速运动

镜头运动应作为自然动作描述书写：

镜头以小幅度、慢速推近她手中折叠的信件。 镜头以大幅度、快速向右摇动，展现敞开的门口。 镜头保持固定不动，跑者走出画面。

④ 说话人、对白与歌唱

使用稳定 ID (S1)、(S2)。多人一起发声用 (S1,S2)。说话人首次出现时从视觉和音频语境提供足够信息。身份短语、ID、动作和表达方式放在 <d> 之外，<d> 内只包含语言标签和实际口语内容，逐字保留原文。

声音轻柔、略带气声的年轻女子 (S1) 说道：<d>[English] I get off at the next station.</d> 两个孩子 (S1,S2) 一起喊道：<d>[English] Wait for us!</d>

画外音使用“以画外音说道”，并在每个 <d> 段落后说明嘴唇保持紧闭。

跨切换的对白使用 <scenetrans>，被截断的语音使用 <cutoff>。

⑤ 画面文字

将画面上可见的文字放在双引号中，逐字保留原文。

一块写着“营业中”的红色霓虹招牌在门口上方发光。

⑥ overall_soundscape（整体音景）

用 1‑4 句概括环境音、物理动作音效和非语言人声。对白、歌唱和画面内音乐不在此重复。仅当完全静音时使用 N/A。

overall_soundscape: 稳定的雨声敲打着咖啡馆的窗户，低沉的室内环境音持续在底层。入口的门铃响了一声，随后是湿漉漉的脚步声和椅子轻微的刮擦声。

⑦ non_diegetic_music（画外配乐）

用 1‑3 句描述角色听不到的背景音乐，重点描述配器、速度、节奏和动态变化。不用抽象情绪词。没有时使用 N/A。

non_diegetic_music: 稀疏的钢琴音符以缓慢的节奏出现，伴随持续的低音弦乐逐渐增强音量后淡出。
🧒
五岁解释： 编写规则就像写作文的“好词好句”模板：
• 镜头运动就是“摄像机怎么动”，比如推近、摇动。
• 说话人就是“谁在说话”，要给每个人一个编号，这样不会搞混。
• 画面文字就是“屏幕上的字”，要原样写出来。
• 音景和配乐就是“背景声音”和“背景音乐”，分开描述。

1.5 完整案例

T2VA

integrated_multimodal_description: [Shot 1] 实拍风格，电影感，一个中远景镜头框住日出前，一位面包师正在打开街边小面包店的卷帘门。镜头以小幅度、慢速推近，中年面包师用平静、略带沙哑的声音 (S1) 把一条新鲜的面包放在木质柜台上，说道：<d>[English] First batch of the morning.</d> [Shot 2] 在 00:05.000 时，镜头切至切片面包冒出蒸汽的特写，面包师的最后一句话延续自上一镜头。 overall_soundscape: 木质卷帘门在安静的街道上刮擦着打开，托盘在面包店里发出轻柔的碰撞声。门铃响了一声，随后是轻快的脚步声和面包被切开时清脆的声音。 non_diegetic_music: 柔和的原声吉他以中速演奏，伴随稀疏的低音提琴音符，在结尾处轻柔地淡出。
🧒
五岁解释： 这些案例就像“范文”，你看懂一个，其他就都会了。记住三个部分：
• 画面故事（integrated...）
• 环境声音（overall...）
• 背景音乐（non...）

🔁 第二部分：全参考模式 (Full‑Reference)

🧒
五岁解释： “全参考模式”就是你给AI看一些“参考材料”（图片、视频、音频），让它照着这些材料的样子来生成新视频。就像你照着乐高说明书搭积木一样。

2.1 整体结构与输出字段

全参考模式改写输出由以下六个部分按顺序组成：

部分作用
subject_definitions定义被引用的内容及其引用标签
summary概括任务类型、目标视频及主要引用关系
retention_analysis描述被引用内容如何被保留、迁移或复用
detailed_description按播放顺序描述画面、动作、镜头、声音和对白
overall_soundscape概括环境音与物理声音
non_diegetic_music描述只有观众能听到的背景音乐
🧒
五岁解释： 这六个部分就像写作文的“提纲”：
1. 先列出来参考了哪些东西（定义）。
2. 概括一下要做什么（摘要）。
3. 分析哪些参考被用了，哪些改了（保留度分析）。
4. 详细写画面和声音（详细描述）。
5-6. 最后再专门写环境音和背景音乐。

2.2 引用标签定义

<Subject N> 从参考素材中抽象出的、可在目标视频中复用或修改的可见内容（人物、场景、服装、动作、风格等） <Picture N> 作为具体目标帧或分镜规划锚点的参考图像 <Video N> 提供剪辑源、延续起点或整段视频时间结构的参考视频 <Audio N> 被复制或引用的音频信号

一旦赋予引用标签，该标签在全部六个部分中保持相同含义。subject_definitions 需定义后续必须单独追踪的每一段被引用内容。

🧒
五岁解释： “引用标签”就像给参考材料起外号：
• <Subject>：外号“角色” — 指人、动物或东西。
• <Picture>：外号“照片” — 指一张图片。
• <Video>：外号“视频” — 指一段视频素材。
• <Audio>：外号“声音” — 指一段音频。
之后写提示词时，就用这些外号代替长长的描述。

<Subject N> 示例

<Subject 1> 是 <Picture 1> 中的年轻女子，留着深色长发，穿蓝色开衫，戴一条细银项链。

<Picture N> 示例

<Picture 2> 是 [Shot 1] 的首帧，展示一位女子坐在咖啡馆窗边。

<Video N> 示例

<Video 1> 是目标视频剪辑所使用的源视频。

<Audio N> 示例

<Audio 1> 是 <Subject 1> (S1) 的音色参考。

2.3 摘要 & 保留度分析

摘要 (summary)

以方括号任务类型前缀开头：

[reference generation] …… [video editing + reference generation + audio reuse] ……
任务类型使用场景
keyframe completion图像作为首帧、关键帧、末帧等具体帧锚点
reference generation为角色、场景、风格等提供生成指导，但不作为具体帧
video editing直接修改一段已有的源视频
video continuation新内容从已有源视频延续、扩展
audio reuse同一音频信号被全部或部分复用
audio reference仅引用音乐风格、音色、对白内容等，未直接复制信号

保留度分析 (retention_analysis) —— 专属标记全解析

这个部分的作用是： 明确告诉 AI，对于你给的参考素材（图片/视频/音频），哪些必须“原封不动”，哪些可以“自由发挥”。如果没有它，AI 可能会随意更改你喜欢的角色长相，或者完全不按参考风格来生成。

标记 中文含义 🧒 五岁解释 💡 具体例子
fully_preserved 完全保留 “这个必须完全照抄，一点都不能变！” 定义里说 Subject 1 是“穿蓝色开衫的女子”，标记为 fully_preserved，AI 生成的视频里她必须穿蓝色开衫，换成红色就不行。
partially_preserved 部分保留 “这个你可以改一改，但得保留一些原来的特点。” 定义里说角色是“长发”，标记为 partially_preserved，AI 可以把她的发型改成“马尾辫”，但“长发”这个属性还在。
attribute_transfer 属性迁移 “把这个东西的特点，拿给另一个东西用。” 参考视频里是“猫跳跃的动作”，标记为 attribute_transfer，AI 可以让你的“狗”做出这个跳跃动作，动作保留了，但执行者变了。
weak_reference 弱引用 “你大概照着这个感觉来就行，细节不用一模一样。” 参考图是一张“复古咖啡馆”的照片，AI 只要生成一个“同样有复古感觉的咖啡店”就行，墙上的画、桌子的摆放可以不照搬。

🎵 音频专属标记

标记 中文含义 🧒 五岁解释 💡 具体例子
fully_copy 完整复制 “这个声音原样复制贴上去。” 直接把参考音频文件作为目标视频的完整音轨，不加任何修改。
partially_copy 部分复制 “只复制一部分，其他我自己加。” 只复制参考音频里的“雨声”层，但自己重新配了“脚步声”和“背景音乐”。
reference 引用（音色/风格） “模仿这个人的声音特点来说新的话。” 参考了某位声优的音色和语速，但让 AI 念一段全新的台词，而不是复制原话。
weak_reference 弱引用 “大概像这种感觉就行，不用完全一样。” 参考一段“欢快的流行音乐”作为风格方向，AI 自己创作一段类似氛围的新配乐。
🧒
五岁总结： “保留度分析”就是给 AI 的“使用说明书”，告诉它哪些参考要原样照搬，哪些可以自己发挥。
• fully_preserved = 必须一模一样。
• partially_preserved = 可以小改。
• attribute_transfer = 把特点借给别的东西。
• weak_reference / reference = 大概照着感觉来，细节随意。

📖 实战案例（来自指南中的“完整示例”）

<Subject 1>（出现于 [Shot 1]、[Shot 2]、[Shot 3]）：fully_preserved —— 裸露的砖墙、橙色簇绒沙发、图案抱枕、霓虹招牌和木质咖啡桌均被保留。

<Audio 1>：reference —— 其人声音色引导 <Subject 3> 的对白表达方式，但未复制原始信号。

🔍 解读：
• 对于 Subject 1（咖啡馆环境），标记为 fully_preserved。这意味着无论镜头怎么切（3个镜头都有它），红砖墙、橙色沙发、霓虹灯这些元素都必须原封不动地出现在每一个画面里。因为这是故事发生的“固定舞台”。
• 对于 Audio 1（参考人声），标记为 reference。这意味着 AI 不能直接复制这段录音里的原话，而是要去模仿这个人说话的音色、语速和语气。AI 会生成新的句子（比如台词），但听起来像同一个人在说话。

🤔 为什么它很重要？

如果没有 retention_analysis，AI 可能会：

  • 把你给的“红砖墙咖啡馆”随机改成“蓝色墙面的餐厅”。
  • 把你喜欢的“低沉嗓音大叔”配成“尖细的卡通音”。

有了它，AI 就能严格遵守你的创意意图——核心要素（fully_preserved）绝对不变，非核心要素（weak_reference / reference）灵活发挥。就像给 AI 戴上了“精准导航”，确保它生成的东西既符合参考，又不会死板到毫无创意。

2.4 详细描述 (detailed_description) 编写要点

基本格式 与第一部分共用规则一致，但有以下全参考模式差异：

维度T2VA全参考模式
主字段integrated_multimodal_descriptiondetailed_description
风格开头写在 [Shot 1] 之后在 [Shot 1] 之前用一到两句话确立
引用信息不使用全参考标签在首次出现及角色适用处插入 <Subject N>、<Picture N>、<Video N>、<Audio N>
音频关系描述目标视频自身的声音在对应镜头或音频阶段引用 <Audio N>，说明信号复制或引用

说话人与音频来源： 当被引用主体实际发声时，同时保留视觉引用标签和说话人 ID：

<Subject 2> (S1) 转向那位女子，说道：<d>[English] Last summer, I went to my grandfather's house. He talked about you.</d>

如果口语内容仅是直接复用的背景音乐中的一句歌词提示，且没有具体人物实际发出该声音，使用 <Audio N> 作为可听来源，不虚构 (Sx)。

🧒
五岁解释： 全参考模式的“详细描述”和普通模式差不多，但多了“引用标签”。
你要在出现角色、图片、视频、声音的地方，用它们的外号（标签）标记出来，就像在作文里加括号注明“这段是参考了哪张图”。
